# Avalonia デモ

> [English version](/docs/avalonia-demo/)

リポジトリの [`EditingSystem/Jewelry.EditingSystem.Avalonia.Demo`](https://github.com/YoshihiroIto/EditingSystem/tree/master/EditingSystem/Jewelry.EditingSystem.Avalonia.Demo) には Avalonia 12 のサンプルがあります。
